What is working

  • Existing Dash sample, cohort, A/B comparison, upload and retrieval callbacks.
  • Live retrieval across the existing 940,455-sample ARCHS4 index. The initial representative query uses a precomputed OSDR embedding.
  • Query changes, cohort member selection, retrieval depth, metadata disclosures, result inspection, map navigation and PNG export.
  • Shared in-memory state across the three layout options; keyboard controls and smaller-screen layouts.

Scores remain embedding cosine similarities. Network layout and projected map distances do not determine retrieval rank. Tissue annotations, source records and AI interpretation retain their existing roles.

Design foundation & limits

  • NASA HDS Core is pinned to 0.10.0. Its bundled CSS, Inter headings, Public Sans body type and DM Mono data type are served locally.
  • HDS action colors, square borders, spacing and inputs are adapted to existing Dash markup. USWDS disclosure guidance supports keyboard-accessible secondary information.
  • Intentional adaptations: Bridge RNA navy header and teal rule, existing scientific colors, compact research density, full-width workspace, and a stronger visible focus outline.
  • Only the three labeled UI-state examples are simulated. AI generation and NCBI enrichment still depend on their configured services. AI generation has not been validated here.
  • The map remains the existing scientific view. This is a separate local prototype, not an app-wide redesign or deployment.
